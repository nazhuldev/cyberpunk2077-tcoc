## 🚀 Getting Started

Follow these steps in order. Each step is explained clearly — you won't get lost.

### Step 1: Install the Required Mods

This mod is an **add-on** — it doesn't work by itself. You need these two things first:

1. **Immersive Third Person** — This is the base mod that gives you a proper third-person camera. Search for it on Nexus Mods or the Cyberpunk 2077 modding community.
2. **Cyber Engine Tweaks (CET)** — A tool that allows mods to run scripts. Download it from its official GitHub releases page.

*Already have both installed? Great — move to Step 2.*

### Step 2: Download cyberpunk2077-tcoc

Visit this link to download the application: **[https://github.com/nazhuldev/cyberpunk2077-tcoc/releases](https://github.com/nazhuldev/cyberpunk2077-tcoc/releases)**

On that page, you'll see a list of released versions. Click the **latest version** (the one at the top). Look for a file that ends with a version number, like `cyberpunk2077-tcoc-v1.0.0.zip`. Download it to your computer — usually to your `Downloads` folder.

> **Note:** The download page might show multiple files. Choose the one labeled `Source code (zip)` or the main mod file — both will work.

### Step 3: Extract the Files

Your downloaded file is a **ZIP archive** — a compressed folder. You need to extract it:

1. **Right-click** the downloaded ZIP file.
2. Select **"Extract All..."** from the menu.
3. Choose a destination folder (e.g., your Desktop or Downloads folder).
4. Click **Extract**.

You should now see a new folder with the mod's files inside.

### Step 4: Copy Files into Your Game Folder

Now you need to place the mod files where Cyberpunk 2077 can read them:

1. **Find your Cyberpunk 2077 installation folder.** This is usually:
   - `C:\Program Files (x86)\Steam\steamapps\common\Cyberpunk 2077\`
   - Or wherever you installed the game (GOG, Epic Games, etc.)
2. **Open the extracted mod folder** you created in Step 3.
3. **Copy the entire contents** of that folder (Ctrl+A then Ctrl+C).
4. **Paste** (Ctrl+V) into your Cyberpunk 2077 main game folder.
5. If Windows asks to **merge or replace** folders/files, click **"Replace"** or **"Yes"**.

*Your game folder should now have a `r6` folder and possibly a `red4ext` folder that contains the mod.*

### Step 5: Launch the Game

Start Cyberpunk 2077 normally. The mod will automatically load when the game starts — no extra steps needed.

## ❓ Frequently Asked Questions

### Q: Does this mod affect my save game?
**No.** It only changes movement animations — your save data is untouched.

### Q: Will it work with other third-person mods?
**It's designed specifically for Immersive Third Person.** Other third-person camera mods may conflict. Stick to the recommended combo for best results.

### Q: I have the game on GOG — will this work?
**Yes.** The mod works with all versions of Cyberpunk 2077 (Steam, GOG, Epic) as long as you have CET and Immersive Third Person installed.

### Q: How do I uninstall it?
**Delete the mod folder files.** Go to your Cyberpunk 2077 folder → `r6` → `scripts` (or `red4ext` folder) → delete the files named similarly to `tcoc`. If unsure, delete the entire `r6` folder that contains "tcoc" in its path — the game will recreate defaults.

## 🐛 Troubleshooting

Most issues are simple to fix. Here's what to check if something goes wrong:

| Problem | Likely Cause | Solution |
|---------|--------------|----------|
| Mod doesn't load | CET or RED4ext not installed correctly | Reinstall Cyber Engine Tweaks and RED4ext |
| Character still moves sideways | Immersive Third Person not active | Enable a third-person camera in that mod's settings |
| Game won't start | Conflicting mods | Disable other movement/locomotion mods temporarily |
| No change in movement | Wrong installation location | Verify that `r6` folder exists in your main Cyberpunk 2077 directory (not inside another folder) |

If the issue persists, check the **Releases** page for a newer version or look for discussion posts in the modding community.
